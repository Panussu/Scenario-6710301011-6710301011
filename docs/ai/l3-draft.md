# ร่างข้อกำหนดสำหรับการกรองและเรียงหนัง

## ข้อกำหนดที่ทดสอบได้

- **REQ-1.** ผู้ใช้เลือกเรตได้จาก G, PG, PG-13, R และ NC-17 ตรวจจากตัวเลือกที่แสดง
- **REQ-2.** เมื่อเลือกเรต ผลลัพธ์มีเฉพาะหนังที่ตรงกับเรตนั้น เช่น เลือก PG-13 แล้วเห็น Men In Black และไม่เห็น Alien ที่ได้เรต R
- **REQ-3.** เมื่อเปิดรายการทั้งหมด ให้แสดงหนังใหม่ก่อน เกณฑ์ที่จะใช้วัดความใหม่รอคำตอบจากลูกค้า
- **REQ-4.** การดูและกรองรายการทำได้โดยไม่ล็อกอินหรือกรอกข้อมูลส่วนตัว ระบบไม่เก็บข้อมูลส่วนตัว

## เรื่องของผู้ใช้

### Story 1 · กรองตามเรต

- As a ผู้ปกครองที่กำลังเลือกหนังให้ลูก
- So that ฉันเจอหนังที่ตรงกับเรตที่ต้องการเร็วขึ้น
- I want เลือกเรตเองและดูเฉพาะหนังที่ตรงกับเรตนั้น

**เกณฑ์ยอมรับ** ในรายการที่มีทั้ง PG-13 และ R การเลือก PG-13 จะเหลือเฉพาะหนัง PG-13

### Story 2 · ดูหนังใหม่ก่อน

- As a คนดูหนังที่เปิดรายการทั้งหมด
- So that ฉันเจอหนังใหม่ได้ง่าย
- I want เห็นหนังใหม่ก่อนในรายการทั้งหมด

**เกณฑ์ยอมรับ** เมื่อมีหนังสามเรื่องที่มีวันที่ต่างกัน รายการต้องเรียงครบทั้งสามจากใหม่ไปเก่าตามวันที่ที่ลูกค้ายืนยัน

### Story 3 · เข้าใจผลกรองว่าง (ข้อเสนอ)

- As a ผู้ปกครองที่เลือกเรตแล้วไม่พบหนัง
- So that ฉันรู้ว่าเหตุใดจึงไม่เห็นรายการหนัง
- I want เห็นสถานะเมื่อไม่มีหนังตรงเรตที่เลือก

**เกณฑ์ยอมรับเบื้องต้น** ผลกรองไม่มีแถวหนัง วิธีสื่อสารว่ารายการว่างรอคำตอบจากลูกค้า

## ตัวอย่าง Gherkin ของ Story 1

```gherkin
Feature: Filter movies by rating

  Background:
    Given a movie "Men In Black" rated "PG-13" released in 1997 is in the catalog
    And a movie "Alien" rated "R" released in 1979 is in the catalog

  Scenario: Show only movies with the selected rating
    When I filter movies by rating "PG-13"
    Then I should see "Men In Black"
    And I should not see "Alien"

  Scenario: No movie matches the selected rating
    When I filter movies by rating "G"
    Then I should see no movies
```

## สมมติฐานและคำถามค้าง

- ตัวอย่างใช้การเลือกทีละเรต ยังต้องถามว่ารองรับการเลือกหลายเรตพร้อมกันไหม
- เมื่อไม่มีหนังตรงเรตจะไม่มีแถวหนัง ส่วนข้อความและวิธีแสดงผลยังไม่กำหนด
- เกณฑ์ของคำว่า “หนังใหม่” ต้องยืนยันก่อนกำหนดลำดับที่ตรวจได้
- ระบบช่วยกรองตามเรตที่ผู้ปกครองเลือก ความเหมาะสมกับเด็กแต่ละคนเป็นการตัดสินใจของผู้ปกครอง
- ขอบเขตในแลบใช้ Java และไม่มีฐานข้อมูล
